# OpenAidy User Docs

These docs cover what you need to know as an operator of OpenAidy — setting up the platform, running agents, scheduling jobs, and connecting channels.

## Start here

- [Getting Started](./getting-started) — install, configure, and run OpenAidy for the first time
- [Sessions](./sessions) — how conversations and context work in OpenAidy
- [Agents](./agents) — how AI agents are dispatched, streamed, and configured
- [Scheduler](./scheduler) — automate agent work with cron jobs and one-shot tasks
- [Channels](./channels) — connect messaging platforms so agents can handle real conversations

## What you can do with OpenAidy

Run AI agents in persistent sessions, schedule automated tasks, connect WhatsApp and other messaging channels, and extend the platform with plugins — all from a single server you run yourself.

## Before you begin

OpenAidy is a self-hosted platform. You need:

- Node.js 22+
- pnpm 10+
- A server or machine to run it on (local or cloud)

See [Getting Started](./getting-started) for the full setup steps.
